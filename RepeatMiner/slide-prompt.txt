SLIDE 2 — How We Used Suffix Arrays (the idea, with example)
Explain: a suffix = the document from some word to the end. Sort all n suffixes.
KEY PROPERTY: every occurrence of a repeated phrase becomes ADJACENT in the sorted
list — so finding repeats becomes finding neighbours, no pair-by-pair comparing.
Use this worked example (word IDs are first-seen order):
  Document: [the, cat, the, cat, sleeps] → IDs [0, 1, 0, 1, 2]
  All 5 suffixes sorted:
    SA index | suffix                 | LCP | shared phrase
    0        | the cat the cat sleeps |  0  | —
    1        | the cat sleeps         |  2  | "the cat"  <- repeat found!
    2        | cat the cat sleeps     |  0  | —
    3        | cat sleeps             |  1  | "cat"
    4        | sleeps                 |  0  | —
  SA = [0, 2, 1, 3, 4]. Point out: the two suffixes starting with "the cat"
  (positions 0 and 2) landed next to each other. The LCP column stores HOW MANY
  words neighbouring suffixes share — lcp[1]=2 literally IS the phrase "the cat"
  occurring twice.

SLIDE 3 — Building the Suffix Array: Prefix Doubling (code snippet)
Idea first: comparing whole suffixes costs O(n) each -> too slow. Trick: ranks.
Rank each suffix by its first 1 word, then reuse ranks to order by first 2, 4, 8…
words — each round only compares two small integers. Stop when all ranks differ.
Real snippet from our SuffixArray.java (show exactly this):

    // Prefix doubling: rank pairs describe the first p tokens, then 2p, ...
    for (int p = 1; ; p <<= 1) {
        for (int i = 0; i < n; i++) {
            nextKey[i] = i + p < n ? rank[i + p] : -1;   // -1 = ran past the end
        }
        sortSuffixArrayByPair(n);      // our own stable merge sort on (rank, nextKey)
        boolean allDistinct = reassignRanks(n);
        if (allDistinct || p >= n) break;
    }

Notes: sorting key is the pair (rank, nextKey); a suffix that runs past the end gets
nextKey = -1 which correctly sorts first (shorter < longer). Sorted by pairs with our
own merge sort (no library suffix machinery). Honest complexity: O(log n) rounds x
O(n log n) merge sort = O(n log^2 n) time, O(n) extra memory.

SLIDE 4 — LCP Array in O(n): Kasai's Algorithm (code snippet)
Idea first: naive way re-compares every adjacent suffix pair from scratch = O(n^2).
Kasai walks suffixes in TEXT order carrying h = the LCP just measured; chopping the
first word from two suffixes that shared h words leaves h-1 shared words, so the
next comparison resumes from h-1, not 0. h drops at most 1 per step -> at most 2n
comparisons TOTAL.
Real snippet from our LCPArray.java (show exactly this):

    int h = 0;
    for (int i = 0; i < n; i++) {              // text order, not sorted order
        int saIndex = inverse[i];
        if (saIndex > 0) {
            int predecessor = suffixArray[saIndex - 1];
            while (i + h < n && predecessor + h < n
                    && text[i + h] == text[predecessor + h]) {
                h++;                            // resume from previous h, not 0
            }
            lcp[saIndex] = h;
            if (h > 0) h--;                     // Kasai's step
        } else h = 0;
    }

Complexity: O(n) time, O(n) memory (inverse permutation array).

SLIDE 5 — From LCP Values to Phrases: the Interval Sweep (code snippet)
Idea first: every repeated phrase = one contiguous block in SA where all internal
LCP values >= phrase length. One stack pass finds all blocks. On pop, emit every
depth from max(l, below)+1 up to the popped depth (this catches nested phrases like
"the" inside "the cat"); frequency = block width.
Real snippet from our PatternDetector.java (show exactly this):

    while (top >= 0 && stackValue[top] > l) {
        int depth = stackValue[top];
        int start = stackStart[top];
        top--;                                  // interval ended: pop it
        int count = i - start;                  // block width = frequency
        int below = top >= 0 ? stackValue[top] : 0;
        int lowest = Math.max(l, below) + 1;
        for (int d = lowest; d <= depth; d++) { // emit ALL nested depths once
            if (d >= params.minPhraseLength() && count >= params.minFrequency()) {
                all.add(new PatternResult(phraseFor(start, d), d, count));
            }
        }
    }

Example output on the slide-2 text: "the cat" x2, "the" x2, "cat" x2. Each phrase is
emitted exactly once — no hash dedup needed. Sweep is O(n); results sorted by
frequency descending, then length descending, then alphabetical; capped at max
patterns.
